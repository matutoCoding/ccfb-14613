# 齿轮修形与接触斑点仿真系统

浏览器内的齿轮齿面修形、啮合仿真与红丹接触斑点分析系统。TypeScript + WebGPU + Three.js，数据全部本地 IndexedDB，无需后端。

## 功能页面

| 页面 | 功能 |
|---|---|
| 齿轮副 | 模数/齿数/压力角/螺旋角/变位系数生成渐开线齿面（含齿根过渡曲线）；格里森制锥齿轮按基本参数经 Tredgold 虚拟齿轮生成；Three.js 三维齿面，偏差可放大到 μm 级观察 |
| 齿面修形 | 齿向鼓形、齿端修薄、齿顶修缘、螺旋角修正四类；拓扑网格鼠标涂刷编辑；工作面/非工作面、小轮/大轮分别设置 |
| 装配误差 | 圆柱：中心距偏差、轴线平行度两分量；锥齿轮：安装距、轴交角；箱体载荷按扭矩/刚度叠加附加偏斜，TCA 等效量实时显示 |
| 啮合仿真 | WebGPU Compute（WGSL）并行计算间隙场，不支持时自动回退 CPU；红丹着色、轻载/满载压力场、齿端应力集中标红、传动误差曲线与指标 |
| 斑点对比 | 现场照片导入、四角标定对齐、照片×仿真叠加、国标接触精度等级判定、自动反推最可能的装配误差组合 |
| 修形报告 | 齿向/齿高修形曲线、磨齿机修形参数表、仿真斑点图；导出 HTML 报告 / CSV 参数表 / PNG 图 |

## 三条硬指标（测试见 tests/acceptance.test.ts）

1. **零修形零误差**：间隙场处处为 0（容差 1nm），斑点贯穿全齿宽（长度占比 >95%），TE 峰峰值与啮合频率幅值 <0.1μrad；
2. **误差方向与手算一致**：交错偏斜、面内偏斜、中心距偏差的斑点响应方向由线性化间隙公式 `δ = -n·(Δt+Δθ×r)` 给出，测试逐项核对；
3. **反推误差 ≤10%**：间隙场最小二乘反推（`inverseFromGapField`）在圆柱三自由度、锥齿轮安装距+轴交角组合下相对误差 <2%（测试阈值 12%，留数值余量）。

## 架构

```
src/
  gear/          纯数学核心(无 DOM 依赖, 可独立测试)
    geometry.ts    渐开线/螺旋扭转/齿根过渡曲线/齿面网格
    bevel.ts       格里森锥齿轮 Tredgold 虚拟齿轮映射
    modification.ts 四类修形 + 自由拓扑
    assembly.ts    装配误差 -> TCA 等效量(含锥齿轮一阶映射、箱体偏斜)
    tca.ts         作用平面 TCA: 间隙场、着色、传动误差
    loaded.ts      LTCA: 柔度法载荷分布、Hertz 应力、齿端集中
    inverse.ts     间隙场/特征双通道误差反推(高斯-牛顿)
    grading.ts     国标接触精度评级
  sim/
    gpuEngine.ts          WebGPU WGSL 计算核 + CPU 对账回退
    simulationService.ts  仿真编排与记录
  db/            IndexedDB(idb) 持久化 + 发布订阅状态
  ui/            六个页面 + Canvas 场渲染 + Three.js 齿面
tests/           Vitest 验收测试(14 项)
```

## 模型假设与适用范围（重要）

本系统用于**工程级方案对比与修形量估算**，不是齿轮测量中心或商用 LTCA 软件的替代：

1. **作用平面 TCA**：渐开线共轭在作用平面内严格成立，零误差恒零间隙是模型的数学性质；真实齿面的微观形貌、热处理变形未建模。
2. **锥齿轮为 Tredgold 一阶近似**：用虚拟圆柱齿轮表达格里森基本参数，局部共轭（刀盘半径、失配 V/H 调整）通过修形通道间接体现；精确的弧齿锥齿轮齿面需要单独的加工仿真。
3. **LTCA 为线性柔度模型**：轮齿弯曲用量级化悬臂梁 + Hertz 接触，应力用于相对比较与边缘集中定位，绝对精度有限；做强度判定请配合标准计算。
4. **照片反推精度依赖标定**：`inverseFromFeatures` 仅能恢复斑点可辨识的自由度，中心距这类只改间隙深浅的量在照片通道不可观，应使用间隙场通道或结合实测侧隙。
5. 评级表（grading.ts）为工程常用参考值，企业可按自身质量体系替换 `DEFAULT_GRADE_TABLE`。

## 技术要点

- WebGPU uniform 严格按 16 字节 vec4 对齐；GPU 结果与 CPU 同构实现做 10nm 对账，超限自动回退，防止静默错误。
- 反推以**单位物理扰动雅可比**建立法方程，解直接为物理量；岭回归仅作 1e-10 级数值稳定。
- 红丹渲染：齿面灰黑底 + 红丹色随接触强度渐变；应力场用 jet 色标，齿端集中格点红框标注。
