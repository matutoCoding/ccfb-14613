# 齿轮修形与接触斑点仿真系统

浏览器端齿轮副修形设计与接触斑点(TCA)仿真工具。TypeScript + WebGPU(计算)+ Three.js(三维),数据存 IndexedDB,零后端。

## 运行

```bash
npm install
npm run dev        # 开发
npm test           # 验收测试(vitest)
npm run build      # 类型检查 + 打包
```

## 页面

| 页面 | 功能 |
|---|---|
| 齿轮副 | 圆柱(斜/直齿)与格里森制锥齿轮参数,渐开线+齿根过渡曲线(齿条刀包络),三维预览 |
| 齿面修形 | 齿向鼓形/齿端修薄/齿顶修缘/齿形鼓形/螺旋角修正/自由拓扑网格,修形曲线,三维 μm 级放大 |
| 装配误差 | 中心距偏差、轴线平行度 fx、交错度 fy、箱体变形附加偏斜、锥齿轮安装距偏差 |
| 啮合仿真 | WebGPU 间隙场(无 GPU 自动回退 CPU)、轻载/满载斑点、传动误差、载荷分布、齿端应力集中 |

| 修形报告 | 修形曲线 CSV、磨齿机修形参数表 CSV、斑点图 PNG、完整报告 TXT |

## 计算模型(截面法 TCA)

- 平行轴(或当量)齿轮副,每个端截面等效为二维渐开线啮合;锥齿轮按中点当量圆柱齿轮(Tredgold)进同一模型。
- 间隙场 g(ξ,t):ξ=啮合线坐标,t=齿向坐标。零修形零误差时窗口内 g≡0。
- 装配误差:Δa·sinα′(均布)+ fx·(t−½)·sinα′(中心距锥度)+ fy·(t−½)(法向锥度);中心距偏差同时移动接触窗口(窗口宽度随 a 变化),这是平行度与交错度在斑点上可区分的关键二阶效应。
- 修形量锚定在牙齿坐标(形圆=0→齿顶=1),不随窗口移动。
- 斑点判据:g ≤ G(ξ)+红丹层厚,G 为同相接触点(±k·基节)最小间隙;TE(φ)=G(ξ(φ))−min。
- 加载接触:线接触刚度 c′=20 N/(mm·μm),二分求刚体贴近量,赫兹应力,端部 15% 区域内应力超均值 1.5 倍标记应力集中。
- 误差反推:连续(软)斑点图(sigmoid 接触判据,含窗口边缘 0.05mm 过渡)RMS 匹配,粗网格 + 两阶段 Nelder-Mead。硬掩膜会丢失亚网格信息,反推必须用软图。

WGSL 计算着色器(`src/gpu/gapfield-wgsl.ts`)与 CPU 参考实现(`src/core/tca.ts` 的 `gapAt`)逐行对应,**改动必须两边同步**。

## 验收基准(npm test,9 项全过)

1. 零修形零误差 → 斑点长度/高度 100%,TE 峰峰值 < 1e-6 μm;
2. 正交错度/正平行度 → 接触区偏向左端(右端间隙大),与手算方向一致;
3. 反推误差与真实输入偏差 ≤ 10%(实测 < 0.001%)。

## 已知简化(工程近似,界面已注明)

- 齿根过渡曲线用标准齿条刀(刀尖圆角 0.38m)包络解析式;非标准刀具需改 `involute.ts`。
- 锥齿轮安装距→当量误差为一阶折算;对角接触量为近似。
- 加载接触为单截线柔度模型,未做全齿面影响系数矩阵。
- 接触斑点等级表为 GB/T 10095 典型值,可在 `standards.ts` 调整。
